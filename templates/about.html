About The Website

Pulmora is designed to help users in detecting pneumonia by analyzing X-ray images using artificial intelligence. The website uses a deep learning model called Convolutional Neural Network (CNN) for this. Pulmora also provides more information about pneumonia, its symptoms, prevention, and treatment options. This website was made as part of an IB personal project by Arush Tiwary.

How does the website work?

The website uses a machine learning model called Convolutional Neural Network (CNN) which is trained to look at X-ray images for pneumonia. The model is trained on a large dataset of 5000 labeled X-ray images. This allows it to accurately identify patterns associated with pneumonia. With this training, it is able to detect patterns in new X-ray images uploaded by users that may indicate pneumonia. Users can upload their X-ray images, and the image is passed through the backend which contains the model. The model then provides the user with a diagnosis along with a confidence score, based on how sure the model is on its guess. The model has a training accouracy of ~95%

What is Pneumonia?

Pneumonia is an infection which inflames the alveoli (air sacs) in one or both lungs. During pneumonia, the alveoli may fill with fluid or pus, which can cause symptoms such as cough, fever, and difficulty breathing. Pneumonia can be caused by a variety of different sources, including bacteria (such as Streptococcus pneumoniae), viruses (such as influenza), and fungi. Refer here for more information.

Prevention and Treatment

Preventive measures include vaccination, good hygiene practices, and avoiding smoking. Some treatment options for pneumonia includes: antibiotics for bacterial pneumonia; antiviral medications for viral pneumonia; and antifungal treatments for fungal pneumonia. For more details, visit CDC Pneumonia Prevention.
